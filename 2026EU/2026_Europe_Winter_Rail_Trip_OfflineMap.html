住宿策略

Zürich 與 Interlaken 建議優先採 1 間 Twin/Double + 1 間 Single； Milano、Venezia 可再比較 Triple room 與兩間房的價差。

交通策略

德國段用 DB 單買；瑞士段重點比較 Swiss Half Fare Card； Milano → Venezia 優先 Frecciarossa / Italo； 最後一天威尼斯機場分流搭機。

少女峰不要太早綁死日期。以 12/1 與 12/3 作為主要候選日，11/30 抵達 Interlaken 後再依山頂天氣與 webcam 決定。

每日完整行程

11/28 Sat

Pforzheim → Zürich

上午約 08:30–09:30 出發，預留約 3.5–4 小時。抵達 Zürich HB 後入住中央車站附近飯店；下午散步 Bahnhofstrasse、Lindenhof、Fraumünster、Grossmünster、Niederdorf 與 Zürichsee。

11/29 Sun

Zürich 城市日

完整市區行程：老城、Lindenhof、教堂群、湖畔、Bahnhofstrasse。晚上欣賞冬季與聖誕燈飾，不再額外塞 Lucerne。

11/30 Mon

Zürich → Interlaken

上午約 10:00 從 Zürich HB 出發，優先選直達 Interlaken Ost 的 IC。中午抵達後入住 Ost 附近，下午走 Höhematte、Höheweg 與市區散步。

12/1 Tue

Jungfraujoch 少女峰候選日 ①

若天氣佳：Interlaken Ost → Grindelwald Terminal → Eiger Express → Eigergletscher → Jungfraujoch。山頂停留約 3–4 小時，主要看 Sphinx、Aletsch Glacier、Ice Palace、Plateau。

關鍵優先走 Grindelwald / Eiger Express 線。
12/2 Wed

Lauterbrunnen + Wengen

Interlaken Ost → Lauterbrunnen → Wengen。冬季不安排過多轉乘，以山谷與村落景觀為主；下午回 Interlaken。

12/3 Thu

少女峰候選日 ②／Grindelwald

若 12/1 天氣不佳，今天改上 Jungfraujoch；若 12/1 已成功，則安排 Grindelwald 慢遊，或視體力改為 Thun / Bern 半日。

12/4 Fri

Interlaken → Milano

上午 09:00–11:00 間出發，典型路線為 Interlaken Ost → Spiez → Brig → Domodossola → Milano Centrale。下午入住中央車站附近；晚上看 Duomo 夜景。

12/5 Sat

Milano 經典行程

Duomo di Milano → Galleria Vittorio Emanuele II → La Scala → Brera → Castello Sforzesco → Parco Sempione。若要上 Duomo rooftop，建議排上午。

12/6 Sun

Milano／Como 二選一

若第一次到米蘭，可留市區安排 Santa Maria delle Grazie、Navigli、Porta Nuova；若米蘭已熟悉，建議 Como 一日遊，當天往返、不換飯店。

12/7 Mon

Milano → Venezia

上午約 10:00 搭 Frecciarossa 或 Italo 前往 Venezia Santa Lucia，約中午抵達。下午走 Cannaregio → Rialto → Piazza San Marco，晚上搭 Vaporetto 看 Grand Canal。

提醒目的地選 Venezia Santa Lucia，不是 Mestre。
12/8 Tue

Venezia 本島完整日

Piazza San Marco → Basilica di San Marco → Doge's Palace → Bridge of Sighs → Rialto → San Polo → Dorsoduro → Accademia。

12/9 Wed

Murano + Burano

上午搭船前往 Murano，再到 Burano；不再加 Torcello，避免冬季白天較短導致行程過趕。傍晚回 Venezia 吃最後一晚晚餐。

12/10 Thu

Venezia → VCE → Paris / München

三人一起早餐、退房、前往 Marco Polo Airport。之後分流：2 人飛 Paris（優先比較 CDG / ORY），1 人飛 München（MUC）。航班時間最好相差不超過 2–3 小時，方便一起前往機場。

建議住宿區域

Zürich｜2 晚

Zürich HB 步行範圍。方便抵達、隔天去 Interlaken；避免拖行李穿過太多市區。

Interlaken｜4 晚

Interlaken Ost 周邊。這是去 Grindelwald、Lauterbrunnen、Jungfraujoch 的最佳基地。

Milano｜3 晚

Milano Centrale 周邊。瑞士抵達與前往威尼斯都方便。

Venezia｜3 晚

Santa Lucia / Cannaregio。三人帶大行李，避免跨太多橋；最後一天前往機場也方便。
